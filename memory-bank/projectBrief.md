# Project Brief: Gym Global Athlete PWA

## Overview
**Project Name:** Gym Global Athlete PWA (rokhdad FIT)
**Codebase:** `athlete-pwa/`
**Repository:** `https://git.rokhdad.click/customerapp/customer-portal`
**Status:** Early development — design system foundation complete

## Core Requirements
- **Type:** Progressive Web App for gym/fitness athletes
- **Brand:** rokhdad — Persian-language fitness platform
- **Aesthetic:** "Hevy + Glassmorphism" — pure black canvas, glass surfaces, neon accents
- **Primary Language:** Persian (فارسی) with Vazirmatn font, RTL layout
- **Secondary Language:** English (planned)

## Design System Specifications
| Token | Value |
|-------|-------|
| Background | Pure Black `#000000` |
| Glass Background | `rgba(255, 255, 255, 0.05)` |
| Glass Blur | `10px` backdrop-filter |
| Glass Border | `1px solid rgba(255, 255, 255, 0.1)` |
| Primary Accent | Electric Blue `#3A86FF` |
| Success/Metric | Spring Green `#00E676` |
| Font | Vazirmatn (Arabic subset) via `next/font/google` |
| Direction | RTL (`dir="rtl"`, `lang="fa"`) |

## Key Features (Planned)
1. Workout tracking & logging
2. Gym session booking
3. Real-time training notifications
4. Premium subscription management
5. Partner brand integrations
6. AI coaching & analytics (premium)
7. Step counter & calorie tracking

## Success Criteria
- Mobile-first PWA with offline capability
- Sub-3s First Contentful Paint
- Full Persian localization
- Glassmorphism aesthetic consistency across all surfaces
- Accessible (WCAG 2.1 AA target)

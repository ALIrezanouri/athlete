# Product Context: Gym Global Athlete PWA

## Why This Project Exists
rokhdad is a Persian-language fitness platform that connects athletes to gyms, trainers, and workout experiences. The PWA serves as the primary mobile interface for athletes to track workouts, book sessions, and manage their fitness journey.

## Problems It Solves
1. **No localized fitness app** — Persian-speaking athletes lack a premium, native-language fitness tracking experience
2. **Gym discovery & booking** — Fragmented gym booking process unified into a single interface
3. **Workout accountability** — Streaks, PRs, and real-time notifications keep athletes engaged
4. **Premium coaching access** — AI-powered coaching previously unavailable in the regional market

## How It Should Work
- **Onboarding:** Quick language selection (Persian default) → fitness goal selection → personalized dashboard
- **Daily Use:** View active workout → log sets → track steps/calories → receive notifications
- **Booking:** Browse gym sessions → view availability → book with Magic Card UI → get reminders
- **Premium:** Border Beam-highlighted upsell → subscribe → unlock AI coaching & advanced analytics

## User Experience Goals
- **Feel premium** — Glassmorphism surfaces on pure black create a luxury fitness aesthetic
- **Instant feedback** — Haptic-ready button states, animated lists, shimmer CTAs
- **Zero friction** — Mobile-first PWA with offline support, one-thumb navigation
- **Culturally native** — Full Persian RTL layout with Vazirmatn typography, Toman pricing

## Target Audience
- **Primary:** Persian-speaking gym-goers aged 18–35 in Iran
- **Secondary:** Persian diaspora fitness enthusiasts
- **Tertiary:** Gym owners and certified personal trainers (booking management)

## User Personas (Summary)
1. **Amir (26, Tehran)** — Regular gym-goer, tracks workouts daily, books CrossFit sessions
2. **Sara (31, Isfahan)** — Yoga enthusiast, follows personalized plans, premium subscriber
3. **Reza (24, Shiraz)** — Beginner, needs guidance, motivated by streaks and PR notifications
